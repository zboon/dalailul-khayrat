# Dalāʾil al-Khayrāt

Offline devotional web app: the Dalāʾil al-Khayrāt of Imam al-Jazūlī, divided
for the week, plus the daily litanies (awrād) — in Arabic, transliteration and
English, with a page-for-page Book Version.

A focused companion to the Mawalid app, sharing the same reader and the same
fully cross-referenced Dalāʾil text, without the mawlid collections and qasidas.

## Deploy (GitHub Pages)
Upload all files to a **new** repository and enable Pages. Because it uses its
own `dalail-*` local-storage keys, its bookmarks and settings stay separate from
the Mawalid app even when both are served from the same github.io account.

Files: index.html · sw.js · manifest.json · icon-192.png · icon-512.png · OFL.txt

After deploying an update, open the app twice to clear the old service-worker cache.
